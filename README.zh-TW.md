# 桌面格 DeskGrid

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md)

桌面格（DeskGrid）是 **Stardock Fences 的開放原始碼替代方案**，適用於 Windows 10 和 Windows 11。它可將桌面圖示、資料夾和捷徑整理到獨立的群組面板中。分類及釘選只會儲存檔案路徑，原始檔案會留在原位。

**[下載 Windows x64 版 v2.0.0](https://github.com/Zhaottth/DeskGrid/releases/download/v2.0.0/DeskGrid-2.0.0-windows-x64.zip)** · [建置原始碼](#從原始碼建置) · [回報問題](https://github.com/Zhaottth/DeskGrid/issues)

## v2.0.0 的變更

- 以 Rust 和原生 Win32 重寫，執行時無需安裝 .NET Framework。
- 介面支援简体中文、繁體中文和 English。升級時可讀取舊版的 `layout.xml`。
- 支援在桌面空白處按住滑鼠右鍵框選建立群組，也能將 Windows 桌面上已啟用的系統圖示歸入群組。修正群組歸屬、面板堆疊、拖放和排序等行為。

## 開始使用

解壓縮下載的 ZIP，再按兩下 `DeskGrid.exe` 即可執行。支援 Windows 10 1607 以上版本及 Windows 11。升級前請先從系統匣結束舊版。

按 **Ctrl + Alt + Page Up** 或 **Ctrl + Alt + Page Down**，可在現有桌面頁面之間循環切換。若要更改介面語言，按兩下系統匣圖示開啟管理視窗，進入「設定 → 介面語言」並儲存。

1. 預設群組包括「應用程式與捷徑」「桌面資料夾」「文件與媒體」及「其他桌面項目」。
2. 拖曳標題列可移動面板，拖曳右下角可調整大小。按兩下標題列可摺疊或展開。
3. 將項目拖到其他群組的空白處或一般分頁標籤，或從右鍵選單選擇歸入群組。拖到資料夾圖示、資料夾入口或檔案總管時，由 Windows 執行檔案操作。拖放時按住 Ctrl 可要求複製，拖到資源回收筒則交由 Windows 處理。從檔案總管拖入一般群組的空白處即可釘選。
4. 按兩下系統匣的桌面格圖示可開啟管理視窗。選擇「新增資料夾入口」，即可在桌面瀏覽指定資料夾及其中的子資料夾。
5. 從面板標題列的「…」選擇「與其他面板合併為分頁標籤」。按一下分頁標籤即可切換內容，也可把檔案直接拖至目標標籤。
6. 在「編輯面板」中可調整不透明度、讓圖示套用群組色彩，或設定游標移開時淡出。
7. Windows 桌面上已啟用的「本機」「控制台」等系統圖示可在桌面格中開啟或重新分組。可在「設定」選擇只在桌面格面板中顯示桌面項目，或啟用按兩下桌面空白處來隱藏或顯示面板。
8. 在桌面空白處按住右鍵拖曳出矩形，放開後會在目前頁面的框選位置建立群組，拖曳時按 Esc 可取消。管理視窗右上角的「新增頁面」會建立並切換到空白頁面。「管理頁面」可切換或重新命名頁面，「顯示在哪些頁面」可讓同一面板顯示在多個頁面。
9. 面板可選擇圖示、清單或詳細資料檢視，分別調整圖示大小及摺疊後滑鼠停留展開或收合的延遲。移動面板時按住 Alt 可暫停吸附。
10. 拖曳時圖示預覽會跟隨游標。選擇只在桌面格中顯示桌面項目後，可將檔案項目拖到桌面空白處獨立放置。位置會儲存，按兩下仍可開啟，也可拖回群組重新分類。
11. 在一般群組中，把項目拖到圖示的左半或右半，看到插入線後放開即可排序。資料夾的中央接收檔案，若要排在資料夾旁邊請對準邊緣。資源回收筒固定在第一格。清單及詳細資料檢視使用上下邊緣。拖到內容區的上下邊緣可捲動，按 Esc 可取消。手動排序會自動儲存，也可從「編輯面板 → 排序」改用其他排序方式。

## 快捷鍵與設定

| 操作 | 快捷鍵 |
| --- | --- |
| 隱藏或顯示群組面板 | `Ctrl+Alt+H` |
| 暫時將面板置頂，再按一次退出 | `Ctrl+Alt+Space` |
| 依名稱搜尋所有頁面與面板 | `Ctrl+Alt+F` |
| 上一個桌面頁面 | `Ctrl+Alt+Page Up` |
| 下一個桌面頁面 | `Ctrl+Alt+Page Down` |

系統匣選單也可執行這些操作。介面語言會隨版面配置儲存。管理視窗也支援調整規則優先順序、批次對齊、匯入與匯出版面配置，以及設定登入 Windows 時啟動。

檔案項目來自個人桌面及公用桌面。系統圖示來自目前的 Windows 桌面檢視。啟用資源回收筒時，它會顯示在預設群組的第一格。系統匣選單也提供資源回收筒及本機的入口。版面配置儲存在 `%LOCALAPPDATA%\DeskGrid\layout.xml`。

## 從原始碼建置

在 Windows 安裝 Rust 1.89 或更新版本的 MSVC 工具鏈、Visual Studio C++ 建置工具及 Windows SDK。在專案目錄執行以下命令，產生 `dist\DeskGrid.exe`。

```powershell
.\build.ps1
```

執行 `cargo test --locked` 可檢查舊版版面配置相容性、備份和群組排序。

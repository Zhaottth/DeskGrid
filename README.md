# 桌面格 DeskGrid

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md)

桌面格（DeskGrid）是 **Stardock Fences 的开源平替**，适用于 Windows 10 和 Windows 11。它把桌面图标、文件夹和快捷方式整理到独立的分组面板中。归类和固定操作只保存文件路径，源文件保留在原位置。

**[下载 Windows x64 版 v2.0.0](https://github.com/Zhaottth/DeskGrid/releases/download/v2.0.0/DeskGrid-2.0.0-windows-x64.zip)** · [构建源码](#从源码构建) · [反馈问题](https://github.com/Zhaottth/DeskGrid/issues)

## v2.0.0 的变化

- 用 Rust 和原生 Win32 重写，运行时无需安装 .NET Framework。
- 界面支持简体中文、繁體中文和 English。升级时可读取旧版的 `layout.xml`。
- 支持在桌面空白处按住右键框选建组，并把 Windows 桌面上已启用的系统图标归入分组。修正了分组归属、面板层叠、拖放和排序等行为。

## 开始使用

解压下载的 ZIP，双击 `DeskGrid.exe` 运行。支持 Windows 10 1607 及以上和 Windows 11。升级时先从托盘退出旧版。

按 **Ctrl + Alt + Page Up** 或 **Ctrl + Alt + Page Down**，可在已有的桌面页面之间循环切换。要改界面语言，双击托盘图标打开管理窗口，进入「设置 → 界面语言」并保存。

1. 默认分组包括「应用与快捷方式」「桌面文件夹」「文档与媒体」和「其他桌面项目」。
2. 拖动标题栏移动面板，拖动右下角调整大小。双击标题栏可折叠或展开。
3. 把项目拖到另一分组的空白处或普通标签，或右键选择「归入分组」。拖到文件夹图标、文件夹入口或资源管理器时由 Windows 执行文件操作，按住 Ctrl 拖放可请求复制。拖到「回收站」图标会交给 Windows 处理。把资源管理器中的文件拖到普通分组空白处可以固定它。
4. 双击系统托盘中的桌面格图标打开管理界面。从「添加文件夹入口」选择任意目录，就能在桌面上浏览其中的文件和子文件夹。
5. 用面板标题上的「…」打开菜单，选择「与其他面板合并为标签」。点击标签切换面板内容，也可以把文件直接拖到目标标签上。
6. 在「编辑面板」里调整不透明度，或启用「图标随组着色」「移开指针时淡出」。
7. 「此电脑」「控制面板」等已在 Windows 桌面启用的系统图标会进入桌面格分组，可以打开或移动到其他分组。在「设置」可选择是否只在桌面格面板中显示桌面项目。双击桌面空白处可以隐藏或恢复面板。
8. 在桌面空白处按住右键拖出矩形，松开后会在当前页面的框选位置建立分组。拖动时可按 Esc 取消。用管理窗口右上角的「新建页面」创建并切换到空白页面。左侧的「管理页面」可以切换或重命名页面。通过面板菜单的「显示在哪些页面」，可以让同一面板显示在多个页面上。
9. 面板可选择图标、列表或详细信息视图，独立调整图标大小，并设置折叠后的悬停展开和收起延迟。移动面板时可按住 Alt 暂时关闭吸附。
10. 拖动时图标预览跟随鼠标。当桌面设为只在桌面格内显示时，可以把面板内的文件项目拖到桌面空白处独立摆放。图标位置会保存，双击仍可打开，拖回分组即可重新归类。
11. 在普通分组里，把图标拖到目标项目左半边或右半边，看到插入线后松手即可排到它前面或后面。要排在文件夹旁边，请对准它的边缘。文件夹中央接收文件，回收站固定在第一格。列表和详细信息视图使用上下边缘。拖到内容区上下边缘可滚动，按 Esc 可取消。调整后的顺序会自动保存，可在「编辑面板 → 排序」切回按名称等排序方式。

## 快捷键和设置

| 操作 | 快捷键 |
| --- | --- |
| 隐藏或显示分组面板 | `Ctrl+Alt+H` |
| 将面板临时置顶，再按一次退出 | `Ctrl+Alt+空格` |
| 按名称搜索所有页面与面板 | `Ctrl+Alt+F` |
| 上一个桌面页面 | `Ctrl+Alt+Page Up` |
| 下一个桌面页面 | `Ctrl+Alt+Page Down` |

托盘菜单也可执行这些操作。界面语言随布局保存。管理界面还支持调整规则优先级、批量对齐、导入和导出布局，以及登录时启动。

文件项目来自个人桌面和公共桌面。系统图标来自 Windows 当前的桌面视图。桌面上启用回收站时，它会出现在默认分组的第一格。托盘菜单也提供「回收站」和「此电脑」入口。布局保存在 `%LOCALAPPDATA%\DeskGrid\layout.xml`。

## 从源码构建

在 Windows 上安装 Rust 1.89 或更新版本的 MSVC 工具链，以及 Visual Studio C++ 生成工具和 Windows SDK。在项目目录运行以下命令，生成 `dist\DeskGrid.exe`。

```powershell
.\build.ps1
```

运行 `cargo test --locked` 检查旧版布局兼容、备份和分组排序。

运行 `.\build.ps1 -Package` 可生成带许可文件的 Windows x64 发布 ZIP。打包需要活动工具链的 Rust 文档组件，缺少时可运行 `rustup component add rust-docs`。

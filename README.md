# 桌面格 DeskGrid

桌面格是一个 Windows 桌面整理工具。启动后，它会把桌面文件、文件夹和快捷方式显示在独立的分组面板中。归类和固定操作只保存文件路径，源文件保留在原位置。

## 开始使用

双击 [DeskGrid.exe](dist/DeskGrid.exe)。程序支持 Windows 10 1607 及以上和 Windows 11，需要 .NET Framework 4.8 或更高版本。

1. 默认分组包括「应用与快捷方式」「桌面文件夹」「文档与媒体」和「其他桌面项目」。
2. 拖动标题栏移动面板，拖动右下角调整大小。双击标题栏可折叠或展开。
3. 把项目拖到另一分组的空白处或普通标签，或右键选择「归入分组」。拖到文件夹图标、文件夹入口或资源管理器时由 Windows 执行文件操作，按住 Ctrl 拖放可请求复制。拖到「回收站」图标会交给 Windows 处理。把资源管理器中的文件拖到普通分组空白处可以固定它。
4. 双击系统托盘中的桌面格图标打开管理界面。从「添加文件夹入口」选择任意目录，就能在桌面上浏览其中的文件和子文件夹。
5. 用面板标题上的「…」打开菜单，选择「与其他面板合并为标签」。点击标签切换面板内容，也可以把文件直接拖到目标标签上。
6. 在「编辑面板」里调整不透明度，或启用「图标随组着色」「移开指针时淡出」。
7. 新布局默认隐藏 Windows 原生桌面图标，桌面由分组面板接管显示。双击桌面空白处可以隐藏或恢复面板。管理界面可调整这两项设置，退出桌面格会恢复程序隐藏过的原生图标。
8. 从「管理页面」添加桌面页面。通过面板菜单的「显示在哪些页面」让它出现在一个或多个页面。管理窗口还可以批量对齐面板。
9. 面板可选择图标、列表或详细信息视图，独立调整图标大小，并设置折叠后的悬停展开和收起延迟。移动面板时可按住 Alt 暂时关闭吸附。
10. 拖动时图标预览跟随鼠标。原生图标隐藏时，把图标放到桌面空白处即可独立摆放。图标位置会保存，双击仍可打开，拖回分组即可重新归类。
11. 在普通分组里，把图标拖到目标项目左半边或右半边，看到插入线后松手即可排到它前面或后面。要排在文件夹旁边，请对准它的边缘。文件夹中央接收文件，回收站固定在第一格。列表和详细信息视图使用上下边缘。拖到内容区上下边缘可滚动，按 Esc 可取消。调整后的顺序会自动保存，可在「编辑面板 → 排序」切回按名称等排序方式。

## 快捷键和设置

| 操作 | 快捷键 |
| --- | --- |
| 隐藏或显示分组面板 | `Ctrl+Alt+H` |
| 将面板临时置顶，再按一次退出 | `Ctrl+Alt+空格` |
| 按名称搜索所有页面与面板 | `Ctrl+Alt+F` |
| 切换桌面页面 | `Ctrl+Alt+PgUp / PgDn` |

托盘菜单也可执行这些操作。原生桌面图标可见时，使用快捷键或托盘菜单切换面板显示。管理界面支持规则优先级、按名称通配符或扩展名匹配、按修改时间归类、锁定面板、设置颜色和排序、布局快照以及登录时启动。新文件会自动进入匹配的分组。

分组扫描个人桌面和公共桌面的常规文件项目。回收站位于默认分组「其他桌面项目」的第一格，双击即可打开。托盘菜单的「Windows 系统文件夹」也提供回收站和此电脑入口。布局保存在 `%LOCALAPPDATA%\DeskGrid\layout.xml`。
